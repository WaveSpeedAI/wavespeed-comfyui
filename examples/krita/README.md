# Krita workflows

ComfyUI API-format workflows for the [Krita AI Diffusion](https://github.com/Acly/krita-ai-diffusion)
plugin's Graph workspace. Import them with **Import File** in the plugin's Graph workspace.

| File | Description |
| --- | --- |
| `wavespeed-image-edit.json` | Canvas + prompt to an image-edit model, result scaled back to the canvas |
| `wavespeed-text-to-image.json` | Text to image at the canvas resolution |

Setup instructions: [`docs/krita.md`](../../docs/krita.md).
